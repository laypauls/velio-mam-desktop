## Update rules

- The license ids in the `THIRD_PARTY_NOTICES.md` tables (1.1.1, 1.2, 1.3.1) must each have a `licenses/<id>.txt` (a test checks it); the generator fails otherwise.
- Changing the `ort` version: fetch `ThirdPartyNotices.txt` from the matching onnxruntime tag, rename the file with the
  new version, update `ORT_NOTICES` in `scripts/dump-licenses.mjs`, and regenerate `THIRD_PARTY_LICENSES.md`.
- `GPL-3.0.txt` is copied by `scripts/fetch-sidecars.ps1` into the installer's `licenses\` folder (LGPL-3.0 incorporates it by reference).
- A text must be verified against its source before its hash is changed here.
